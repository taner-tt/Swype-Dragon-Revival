## What this **does not** prove

- The previous `apktool b` success was against an older inspection baseline, **not this new 3722 APK**. Presence of method IDs alone does not verify all smali field offsets or callback runtime correctness.
- No language bridge has been installed into 3722, no new signed APK created, no on-device test run.
- New APK does not itself supply the Swedish ZIP to GitHub. The existing Swedish draft release is not anonymously readable and the public Nuance catalog is empty.
- Correct live Alpha core version and Swedish server version remain to be measured.
- The signing certificate matching an earlier experimental APK does not by itself prove the backup keystore can sign matching updates; verify signer of a newly built test APK.
