# Swype language packs

This directory is reserved for the downloadable language catalog and its metadata.

Planned layout:
- `languages.json` — language names, versions, download URLs and checksums.
- Language ZIP archives should be published as GitHub Release assets, not committed to this folder.

Initial test target: Swedish (`sv`) with English built into the APK.

Status: download, update, installation and uninstall support in the APK are not yet verified end-to-end.

**Licensing:** Do not publish proprietary Nuance/XT9 `.ldb` files or other third-party resources without redistribution permission. Do not upload APK signing keys, keystores or passwords.
